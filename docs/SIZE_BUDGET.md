## 资源包含与验收

- Copy Bundle Resources 包含整份 Nina.zip。可维护的 `web/community/` 目录由打包脚本读取，App 只分发生成的 ZIP。原片、转码比较帧和方向板不进入 iOS 资源阶段。Nina/Resources 除 ZIP 外的源码文件共 1,313,070 B，这个数包含只由 Metro 引用的目录数据、配置和 StoreKit 调试文件。
- ZIP 与解压目录分别占用安装空间。解压目录按资源摘要复用，放在 Application Support 的独立可重建子目录。应用自有档案及用户内容与该目录分开保存。
- 社区与 React Native 页面共用少量 Barlow 字体和原创图标。两套界面各自加载这些小份资源。66 项内容及首帧共用 ZIP 中的唯一分发副本。
- 逐项比对 ZIP 条目与本地输入，检查 16 条影片的解码结果及重编码的代表帧。实际 IPA、真机视频兼容性和断网端到端交互尚未测量。 [资源字节和校验值](media-package-verification.json)
- 欢迎页使用既有原创返回图标，应用内重复品牌展示使用的网页标志副本已移出归档。66 项内容的原有摘要保持一致，ZIP 的全部 98 个条目与网页输入逐字节一致。本次未编译或运行 App。
