## 媒体质量

随包媒体较最初优化副本减少 14,569,695 B（28.6%）。既有 12 条影片使用 HEVC hvc1，保留显示尺寸、帧数与原 AAC 载荷；其余 4 条复用 H.264 产物。当前清理只修改 ZIP 内容集合，不改变图片、影片、音轨或首帧。

此前已记录解码与代表帧检查；这些历史检查不代表当前原生 App 的设备播放验收。[逐项字节和摘要](media-package-verification.json)

## 原生资源与缓存

- 原生资源输入（不含 Nina.zip）为 4,523,672 B，包含实际使用的 Asset Catalog、字体、目录数据、离线协议和 StoreKit 调试文件。此数不是编译后的 Assets.car 或 IPA 体积。
- UI 美术只从原生资源加载，Nina.zip 不再重复分发。当前原创图片源稿仍保留为维护源文件。
- 解包目录按包摘要复用，安装成功后清理旧摘要对应的资源缓存。账号、消息、内购和用户导入媒体位于独立目录。
- scripts/package-media.py 按 LinesCatalog.json 打包。默认重整现有 ZIP，也可提供一份完整媒体文件夹；替换前检查条目、CRC 和逐项 SHA-256。

工程继续以 50,000,000 B 为整包优化目标。当前没有 RN / Hermes 或 JS bundle 构建输入。本轮未编译、运行或测量实际 IPA，最终包体和真机媒体兼容性仍待构建及设备验收。
